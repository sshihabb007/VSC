How to Use Video Speed Controller

1. On-Page Floating Controller

  • Plays cleanly on any native HTML5 <video> (and <audio> when enabled), ranging from 0.07× to 16.00×.
  • Hover over the speed badge to reveal inline buttons: « Rewind, − Slower, + Faster, and » Advance.
  • Double-click the speed number to toggle between reset speed (1.0×) and preferred speed (G).
  • Hover & Scroll: Rest the cursor on the badge for ~0.3s and scroll up/down to step speed by 0.1× without scrolling the page.
  • Drag: Hold and drag the badge to move it anywhere temporarily during playback.

2. Toolbar Extension Popup

  • Click the extension icon in your Chrome or Brave toolbar for an instant speed HUD showing active video speed and multi-video count.
  • Use step buttons (-0.1 / preferred / +0.1) or one-click speed presets from 0.5× to 2.5×.
  • Toggle on-page controller visibility with the eye icon or disable the extension globally with the power button.
  • Use the built-in Position strip inside the popup to re-anchor or nudge the active website live without opening Settings.

Keyboard Shortcuts & Custom Actions

Customize any key, add modifier chords (Ctrl, Alt, Shift, Meta), or add extra actions like Pause, Mute, Increase volume, and Decrease volume under Settings > Shortcuts. Typing inside text fields (including Shadow DOM inputs) is automatically ignored.

Per-Platform & Site-Wise Positioning

Independent Platform Rules

Open Advanced > Controller Positioning to assign separate placements for Global Default, YouTube, Facebook, Instagram, X (Twitter), or any custom domain / /regex/ added via + Add Site.

Corners, Edges & Pixel Offsets

Anchor the pill to any corner or edge (Top-Left, Top, Top-Right, Left, Right, Bottom-Left, Bottom, Bottom-Right), fine-tune with directional nudges (1px / 5px / 10px / 25px) or explicit X/Y pixel offsets, preview live on the 16:9 stage, and click Save to update open video tabs instantly.

Site Rules, Preferences & Backup

  • Site Rules (Advanced): Enter a domain (e.g. example.com) or regex (e.g. /\.edu$/i) to either Disable the extension on that site or initialize a custom per-site default speed (0.07–16).
  • Preferences (Settings): Toggle HTML5 <audio> badge attachment, Remember playback speed across videos, start hidden by default, or Exclusive keyboard shortcuts to stop site players from reacting to your bound keys.
  • Import, Export & Reset: Use the arrow menu next to Save at the top-right to export your configuration as JSON, restore from backup, or reset all preferences cleanly.

Local files (file://) or Incognito mode

Open chrome://extensions (or brave://extensions), open Details on Video Speed Controller, and toggle Allow access to file URLs and/or Allow in Incognito.

Disable the extension on a specific site

In Advanced > Site Rules, add the domain (e.g. example.com) or a regex pattern (e.g. /\.edu$/i) and check Disable.

Set a default speed per site

In Advanced > Site Rules, add a rule and enter a numeric speed (e.g. 2). Leave Disable unchecked.

Interaction between Remember speed and Site Rules

Matching site-rule default speeds initialize playback rate for that domain, whereas global remembered speed applies across sites when enabled.

Resolving shortcut conflicts

Bind chords with Shift, Ctrl, or Alt, rebind keys, or turn on Exclusive keyboard shortcuts in Settings.

Repositioning the controller

Drag the speed badge directly on any video, use the quick position controls in the extension popup, or set exact corners, edges, and X/Y offsets independently per platform under Advanced > Controller Positioning.

Controller not showing

Check Site Rules (Disable unchecked), verify the player uses native HTML5 <video>/<audio>, or toggle visibility (default: V).

SPA navigation (YouTube, etc.)

The extension detects SPA route changes automatically and restores session or site-rule playback speeds.

Audio support

When enabled in Settings, HTML5 <audio> elements receive a persistent floating speed badge.
